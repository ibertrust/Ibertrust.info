亞馬遜向歐代索要 DoC：為什麼檢測機構的“CE 證書”不是 DoC，以及怎樣把 ASIN、型號和檢測報告對上

2026-11-12 · IberTrust Global

GPSR · 歐盟負責人 · 平台索要文件 · 來自我們的實際案例，已匿名化

一個週三下午，平台合規團隊的請求發到了我們的負責人電郵：對五個把我們登記為歐盟負責人的 ASIN，每一個都要提供歐盟符合性聲明（DoC）和技術文件或檢測報告。不是抽查，五個全要。

其中四個很順利：簽好字的聲明、對得上的報告，幾天內就交了。第五個卻變成了一次小調查。一個賣家有正式簽字的 DoC，但上面只寫了一個 ASIN，而他在售的還有好幾個。第二份檔案乍看很齊：檢測機構出的“CE 證書”、一份 EMC 檢測報告、一份 RoHS 報告，但裏面根本沒有符合性聲明。第三份有真正的製造商 DoC，可上面寫的授權代表是另一家公司，而且產品是玩具。這幾份都不能原樣交回平台。

下面講我們在把 DoC 交回平台前會核對什麼，以及賣家最常卡在哪裏。案例中的名稱、產品和編號均已刪去。

為什麼請求會落到負責人頭上

對於受歐盟協調立法管轄的產品，包括 EMC 指令 2014/30/EU 和 RoHS 指令 2011/65/EU，法規（EU）2019/1020 第 4 條要求在歐盟設立的經濟營運者核實歐盟符合性聲明和技術文件已經編制，把聲明留存備市場監管機構查閲，並在收到說明理由的要求時提供文件。《通用產品安全法規》（EU）2023/988 第 16 條把同樣的任務適用於該法規下消費品的負責人。平台來要 DoC，實際上就是在檢驗：listing 上登記的營運者能不能履行這份職責。

這也說明了負責人不能做什麼。根據 EMC 指令第 15(4) 條，製造商通過編制聲明，承擔產品合規的責任。我們的角色是核實聲明存在、並與產品對得上。我們不替製造商起草或簽署 DoC。

檢測機構的“CE 證書”不是 DoC

檢測機構常出一頁紙的“Certificate of Compliance”或“CE 證書”，概括一份檢測報告。它不是歐盟符合性聲明。檢測機構不把產品投放市場，證書上也沒有“本聲明由製造商承擔全部責任出具”的聲明。第 768/2008/EC 號決定附件 III 的聲明範本，以及 EMC 指令附件 IV 自己的範本，包含：

  • 聲明編號（EMC 指令下為可選）以及產品、型號、批次或序列號
  • 製造商或其授權代表的名稱和地址
  • 本聲明由製造商承擔全部責任（sole responsibility）出具的聲明
  • 聲明對象，其標識要能追溯
  • 所符合的歐盟立法
  • 所採用的協調標準或其他技術規範及其日期
  • 如有公告機構參與，寫明該機構
  • 補充信息，以及“代表……簽署”（signed for and on behalf of），寫明地點和日期、姓名、職務和簽名

平台要的 vs 賣家常交錯的

平台要的常被交上來的為什麼不行
由製造商（或以自己名義銷售的品牌方）出具的歐盟 DoC檢測機構的“CE 證書”或“Certificate of Compliance”不是對產品負責的一方出具的；沒有責任聲明
能識別這個 ASIN 的 DoC同系列另一個產品、寫著另一個 ASIN 的 DoC識別不出平台問的那個產品
引用歐盟立法的歐盟聲明UKCA 證書或英國聲明屬於英國（大不列顛）制度
覆蓋在售型號的檢測報告測試型號的系列命名並不明確覆蓋產品上標註型號的報告產品、DoC 和證據之間的鏈條斷了
與 listing 上負責人一致的 DoC寫著另一家公司為授權代表的 DoC同一產品出現兩個不同的營運者

分步說明：圍繞 listing 來做 DoC

  1. 從 listing 出發，而不是從檔案出發。按歐盟各站點列出所有登記了您的 ASIN。英國站的 ASIN 可能和歐盟站不同，要確認實際在歐盟站在售的是哪一個。
  2. 把每個 ASIN 對應到產品、標籤和說明書上印的型號。歐盟委員會《藍皮指南》（Blue Guide）寫明，產品上的識別要素應與歐盟符合性聲明上的一致。
  3. 核對型號在報告覆蓋範圍內。報告通常只測一個型號，再按命名規則列出系列型號。確認您賣的型號符合這個規則。不符合的，先問檢測機構或製造商，再讓人簽字。
  4. 確定由誰出具。通常是製造商。以自己的名稱或商標把產品投放市場的，按 EMC 指令（第 11 條）視為製造商；這種情況下由賣家出具 DoC，我們建議另寫“Produced by”註明工廠。報告申請人、工廠和賣家是三家不同公司時，要寫清它們的關係。
  5. 把所有適用立法寫進同一份聲明。例如 EMC 2014/30/EU，以及經授權指令（EU）2015/863 修訂的 RoHS 2011/65/EU。多部法規都要求 DoC 時，用一份聲明涵蓋全部。帶無線模塊的產品歸入無線電設備指令 2014/53/EU，EMC 指令本身排除這類設備；內置電池還要一併核查電池法規（EU）2023/1542。
  6. 標準和日期照報告抄。
  7. 寫明支持報告：實驗室、報告編號和日期。
  8. 把 ASIN 寫進正文，放在型號旁邊。法定範本裏沒有平台標識，但平台是按 ASIN 把文件和 listing 對上的。
  9. 規範簽署：公司、地點、實際簽署日期、姓名、職務、簽名和公司章，做成清晰的 PDF。

常見錯誤

  • 只寫了一個 ASIN 的簽字 DoC，拿去頂其他 ASIN。
  • 把檢測機構證書當 DoC 交。
  • 包裝上的型號報告裏從沒出現過，比如一個零售型號，看不出屬於被測系列。
  • 交了 UKCA 那套，只因為它和 CE 那套放在同一個文件夾。
  • DoC 上寫著別的代表，往往是以前服務商或英國業務留下的。
  • 列立法時漏了電池或無線模塊。
  • 讓負責人“幫忙填一份”。

哪些情況不適用

  • 玩具。適用玩具安全指令 2009/48/EC，有其自身要求。法規（EU）2025/2509 將自 2030 年 8 月 1 日起取代該指令，屆時由數字產品護照取代符合性聲明。玩具我們單獨、逐案評估。
  • 有公告機構參與的產品。DoC 必須引用公告機構及其證書，這超出本清單的範圍。
  • 不受任何 CE 立法管轄的消費品。沒有歐盟 DoC 可要；按 GPSR，由製造商編制技術文件。
  • 英國市場。另一套制度，另一個代表。

常見問題

一份 DoC 能覆蓋多個 ASIN 嗎？

可以，前提是同一產品或由同一份證據覆蓋的型號。在聲明裏逐個寫明 ASIN 和對應型號。只寫了一個 ASIN 的 DoC 不覆蓋其他 ASIN。

檢測機構能籤 DoC 嗎？

不能。聲明由製造商編制，或在委託書有規定時由其授權代表編制。檢測機構的證書只是支持證據。

報告申請人和賣家不是同一家公司，有問題嗎？

不一定，而且很常見。DoC 應寫明出具聲明的製造商，工廠不同時寫明生產工廠，並列出報告，讓產品到證據的鏈條清楚可查。

歐盟負責人能替我寫 DoC 嗎？

我們不做。DoC 是製造商的責任聲明。我們會把它與 listing、標籤和報告逐項核對，告訴您缺什麼。

我們的 UKCA 證書能用於歐盟嗎？

不能。UKCA 屬於英國（大不列顛）制度。歐盟需要引用歐盟立法的歐盟聲明和 CE 標誌。
