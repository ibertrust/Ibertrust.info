亚马逊向欧代索要 DoC：为什么检测机构的“CE 证书”不是 DoC，以及怎样把 ASIN、型号和检测报告对上

2026-11-12 · IberTrust Global

GPSR · 欧盟负责人 · 平台索要文件 · 来自我们的实际案例，已匿名化

一个周三下午，平台合规团队的请求发到了我们的负责人邮箱：对五个把我们登记为欧盟负责人的 ASIN，每一个都要提供欧盟符合性声明（DoC）和技术文件或检测报告。不是抽查，五个全要。

其中四个很顺利：签好字的声明、对得上的报告，几天内就交了。第五个却变成了一次小调查。一个卖家有正式签字的 DoC，但上面只写了一个 ASIN，而他在售的还有好几个。第二份档案乍看很齐：检测机构出的“CE 证书”、一份 EMC 检测报告、一份 RoHS 报告，但里面根本没有符合性声明。第三份有真正的制造商 DoC，可上面写的授权代表是另一家公司，而且产品是玩具。这几份都不能原样交回平台。

下面讲我们在把 DoC 交回平台前会核对什么，以及卖家最常卡在哪里。案例中的名称、产品和编号均已删去。

为什么请求会落到负责人头上

对于受欧盟协调立法管辖的产品，包括 EMC 指令 2014/30/EU 和 RoHS 指令 2011/65/EU，法规（EU）2019/1020 第 4 条要求在欧盟设立的经济运营者核实欧盟符合性声明和技术文件已经编制，把声明留存备市场监管机构查阅，并在收到说明理由的要求时提供文件。《通用产品安全法规》（EU）2023/988 第 16 条把同样的任务适用于该法规下消费品的负责人。平台来要 DoC，实际上就是在检验：listing 上登记的运营者能不能履行这份职责。

这也说明了负责人不能做什么。根据 EMC 指令第 15(4) 条，制造商通过编制声明，承担产品合规的责任。我们的角色是核实声明存在、并与产品对得上。我们不替制造商起草或签署 DoC。

检测机构的“CE 证书”不是 DoC

检测机构常出一页纸的“Certificate of Compliance”或“CE 证书”，概括一份检测报告。它不是欧盟符合性声明。检测机构不把产品投放市场，证书上也没有“本声明由制造商承担全部责任出具”的声明。第 768/2008/EC 号决定附件 III 的声明范本，以及 EMC 指令附件 IV 自己的范本，包含：

  • 声明编号（EMC 指令下为可选）以及产品、型号、批次或序列号
  • 制造商或其授权代表的名称和地址
  • 本声明由制造商承担全部责任（sole responsibility）出具的声明
  • 声明对象，其标识要能追溯
  • 所符合的欧盟立法
  • 所采用的协调标准或其他技术规范及其日期
  • 如有公告机构参与，写明该机构
  • 补充信息，以及“代表……签署”（signed for and on behalf of），写明地点和日期、姓名、职务和签名

平台要的 vs 卖家常交错的

平台要的常被交上来的为什么不行
由制造商（或以自己名义销售的品牌方）出具的欧盟 DoC检测机构的“CE 证书”或“Certificate of Compliance”不是对产品负责的一方出具的；没有责任声明
能识别这个 ASIN 的 DoC同系列另一个产品、写着另一个 ASIN 的 DoC识别不出平台问的那个产品
引用欧盟立法的欧盟声明UKCA 证书或英国声明属于英国（大不列颠）制度
覆盖在售型号的检测报告测试型号的系列命名并不明确覆盖产品上标注型号的报告产品、DoC 和证据之间的链条断了
与 listing 上负责人一致的 DoC写着另一家公司为授权代表的 DoC同一产品出现两个不同的运营者

分步说明：围绕 listing 来做 DoC

  1. 从 listing 出发，而不是从档案出发。按欧盟各站点列出所有登记了您的 ASIN。英国站的 ASIN 可能和欧盟站不同，要确认实际在欧盟站在售的是哪一个。
  2. 把每个 ASIN 对应到产品、标签和说明书上印的型号。欧盟委员会《蓝皮指南》（Blue Guide）写明，产品上的识别要素应与欧盟符合性声明上的一致。
  3. 核对型号在报告覆盖范围内。报告通常只测一个型号，再按命名规则列出系列型号。确认您卖的型号符合这个规则。不符合的，先问检测机构或制造商，再让人签字。
  4. 确定由谁出具。通常是制造商。以自己的名称或商标把产品投放市场的，按 EMC 指令（第 11 条）视为制造商；这种情况下由卖家出具 DoC，我们建议另写“Produced by”注明工厂。报告申请人、工厂和卖家是三家不同公司时，要写清它们的关系。
  5. 把所有适用立法写进同一份声明。例如 EMC 2014/30/EU，以及经授权指令（EU）2015/863 修订的 RoHS 2011/65/EU。多部法规都要求 DoC 时，用一份声明涵盖全部。带无线模块的产品归入无线电设备指令 2014/53/EU，EMC 指令本身排除这类设备；内置电池还要一并核查电池法规（EU）2023/1542。
  6. 标准和日期照报告抄。
  7. 写明支持报告：实验室、报告编号和日期。
  8. 把 ASIN 写进正文，放在型号旁边。法定范本里没有平台标识，但平台是按 ASIN 把文件和 listing 对上的。
  9. 规范签署：公司、地点、实际签署日期、姓名、职务、签名和公司章，做成清晰的 PDF。

常见错误

  • 只写了一个 ASIN 的签字 DoC，拿去顶其他 ASIN。
  • 把检测机构证书当 DoC 交。
  • 包装上的型号报告里从没出现过，比如一个零售型号，看不出属于被测系列。
  • 交了 UKCA 那套，只因为它和 CE 那套放在同一个文件夹。
  • DoC 上写着别的代表，往往是以前服务商或英国业务留下的。
  • 列立法时漏了电池或无线模块。
  • 让负责人“帮忙填一份”。

哪些情况不适用

  • 玩具。适用玩具安全指令 2009/48/EC，有其自身要求。法规（EU）2025/2509 将自 2030 年 8 月 1 日起取代该指令，届时由数字产品护照取代符合性声明。玩具我们单独、逐案评估。
  • 有公告机构参与的产品。DoC 必须引用公告机构及其证书，这超出本清单的范围。
  • 不受任何 CE 立法管辖的消费品。没有欧盟 DoC 可要；按 GPSR，由制造商编制技术文件。
  • 英国市场。另一套制度，另一个代表。

常见问题

一份 DoC 能覆盖多个 ASIN 吗？

可以，前提是同一产品或由同一份证据覆盖的型号。在声明里逐个写明 ASIN 和对应型号。只写了一个 ASIN 的 DoC 不覆盖其他 ASIN。

检测机构能签 DoC 吗？

不能。声明由制造商编制，或在委托书有规定时由其授权代表编制。检测机构的证书只是支持证据。

报告申请人和卖家不是同一家公司，有问题吗？

不一定，而且很常见。DoC 应写明出具声明的制造商，工厂不同时写明生产工厂，并列出报告，让产品到证据的链条清楚可查。

欧盟负责人能替我写 DoC 吗？

我们不做。DoC 是制造商的责任声明。我们会把它与 listing、标签和报告逐项核对，告诉您缺什么。

我们的 UKCA 证书能用于欧盟吗？

不能。UKCA 属于英国（大不列颠）制度。欧盟需要引用欧盟立法的欧盟声明和 CE 标志。
