服务

欧盟负责人（GPSR）

根据《通用产品安全法规》（EU）2023/988，我们作为设在欧盟境内的经济经营者，为欧盟以外的工厂和跨境卖家担任欧盟负责人。

→

西班牙包装 EPR（皇家法令 1055/2022）

为投放西班牙市场的包装办理生产者注册，并担任授权代表。

→

WEEE / 电子电气设备 EPR

为电子电气设备办理生产者注册、授权代表和申报。

→

电池 EPR（法规（EU）2023/1542）

协助履行电池投放欧盟及西班牙市场的生产者义务。

→

化妆品欧盟负责人与 CPNP 通报

依据化妆品法规（EC）1223/2009，提供欧盟负责人服务和 CPNP 通报。

→

EPREL 能效标签注册

在欧盟 EPREL 数据库中为能源相关产品完成注册。

→

EUDR 尽职调查支持

协助应对《欧盟零毁林法规》的尽职调查声明和供应链溯源要求。

→

西班牙税号（NIF）与增值税代理

常见问题

欧盟以外的卖家需要欧盟负责人吗？

需要。GPSR 实施后，投放欧盟市场的大多数消费品都必须有一家设在欧盟境内的经济经营者，其名称和联系方式要标注在产品、包装或随附文件上。

GPSR 和 EPR 能交给同一家服务商吗？

可以。IberTrust Global 同时提供欧盟负责人、西班牙包装 EPR、WEEE、电池和化妆品 CPNP 服务，您只需对接一个窗口。

你们支持哪些语言？

中文、英文和西班牙语。

怎么获取报价方案？

请发邮件至 contact@ibertrust.info，说明您的产品类别、目标市场和销售渠道，我们会根据情况给出定制方案。

想安心把产品卖进欧盟？

告诉我们您的产品、目标市场和销售渠道，我们会给出定制方案。
