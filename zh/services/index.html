服务

欧盟负责人（GPSR）

根据《通用产品安全法规》（EU）2023/988，我们作为设在欧盟境内的经济经营者，为欧盟以外的工厂和跨境卖家担任欧盟负责人。

→

西班牙包装 EPR（皇家法令 1055/2022）

为投放西班牙市场的包装办理生产者注册，并担任授权代表。

→

WEEE / 电子电气设备 EPR

为电子电气设备办理生产者注册、授权代表和申报。

→

电池 EPR（法规（EU）2023/1542）

协助履行电池投放欧盟及西班牙市场的生产者义务。

→

化妆品欧盟负责人与 CPNP 通报

依据化妆品法规（EC）1223/2009，提供欧盟负责人服务和 CPNP 通报。

→

EPREL 能效标签注册

在欧盟 EPREL 数据库中为能源相关产品完成注册。

→

EUDR 尽职调查支持

协助应对《欧盟零毁林法规》的尽职调查声明和供应链溯源要求。

→

西班牙税号（NIF）与增值税代理

为外国公司申请西班牙税号（NIF），并提供增值税税务代表服务。

→

清关与进出口支持

在清关和跨境贸易单证方面提供实操支持。

→

想安心把产品卖进欧盟？

告诉我们您的产品、目标市场和销售渠道，我们会给出定制方案。
