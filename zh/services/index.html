服务

代表服务

欧盟负责人（GPSR）

根据《通用产品安全法规》（EU）2023/988，我们作为设在欧盟境内的经济经营者，为欧盟以外的工厂和跨境卖家担任欧盟负责人。

→

医疗器械欧盟授权代表（MDR）

根据法规 (EU) 2017/745，为非欧盟制造商担任欧盟授权代表。IberTrust 已在 EUDAMED 完成授权代表登记并获 SRN。

→

REACH 唯一代表（ECHA）

根据法规 (EC) 1907/2006（REACH）第 8 条，为非欧盟的制造商、配方商和物品生产商担任欧盟唯一代表。通过 ECHA 的 REACH-IT 办理。

→

英国负责人 / 授权代表

为英国境外制造商提供设在英国的负责人或授权代表，适用于英国产品法规要求指定英国经营者的产品。

→

土耳其授权代表

为向土耳其市场投放产品的制造商，提供设在土耳其的授权代表。

→

EPR 生产者延伸责任

西班牙包装 EPR（皇家法令 1055/2022）

为投放西班牙市场的包装办理生产者注册，并担任授权代表。

→

WEEE / 电子电气设备 EPR

为电子电气设备办理生产者注册、授权代表和申报。

→

电池 EPR（法规（EU）2023/1542）

协助履行电池投放欧盟及西班牙市场的生产者义务。

→

欧盟其他国家 EPR 注册

为包装、WEEE 和电池办理生产者注册、授权代表和定期申报，覆盖德国、爱尔兰、法国、意大利、奥地利、比利时、瑞典、捷克、罗马尼亚和匈牙利（另含西班牙）。荷兰、波兰可咨询报价。

→

产品通报与注册

化妆品欧盟负责人与 CPNP 通报

依据化妆品法规（EC）1223/2009，提供 CPNP 通报和化妆品欧盟负责人服务。

→

化妆品安全评估报告（CPSR）

依据化妆品法规（EC）1223/2009 第 10 条和附件 I，由具备资质的安全评估员对化妆品进行安全评估。

→

EPREL 能效标签注册通报

依据法规（EU）2017/1369，在欧盟 EPREL 数据库中为带能效标签的产品完成注册，并为欧盟境外供应商担任授权代表。

→

EUDR 零毁林

EUDR 尽职调查声明（DDS）通报

依据《欧盟零毁林法规》（EU）2023/1115，在欧盟信息系统中准备并提交尽职调查声明，并可担任授权代表。

→

EUDR 溯源与风险评估报告

针对一个产品类别，结合供应链梳理和卫星数据核查生产地块，形成书面的溯源与毁林风险分析报告。

→

西班牙税务

西班牙税号（NIF）与增值税代理

为外国公司申请西班牙税号（NIF），并提供增值税税务代表服务。

→
